# Literature search

## Build the query

- Split the question into concepts: the **exposure** (e.g. "vitamin D supplementation"), the **outcome** (e.g. "25-hydroxyvitamin D"), and the **people** only if it matters (e.g. "pregnancy", "older adults").
- Within a concept, join synonyms with OR; join concepts with AND. Use the terms researchers use: "ferritin" and "iron stores"; "LDL cholesterol" and "low-density lipoprotein"; "omega-3", "fish oil", "EPA", "DHA".
- If a PubMed MCP tool is connected, MeSH terms (e.g. "Hypercholesterolemia"[MeSH]) find studies that use different wording.
- Never put the user's personal details (name, results, dates) into a search. Search for the topic, not the person.

## Filter and pick

1. First look for **guidelines, systematic reviews and meta-analyses** (`search_research` with filter "reviews").
2. If there are none or they are old (more than about 10 years), look for **randomised trials** (filter "trials").
3. Prefer human studies, recent ones, and larger ones. Note the population: results in athletes, children or people with a disease may not apply.
4. Read the abstract before citing: the title can overstate the finding.

## Report

- Say how many studies you looked at and which kind, and that search results are sorted by relevance, not quality.
- Cite with the ID exactly as returned, e.g. [PMID:12345678] or [PMCID:PMC1234567]. Only cite what you retrieved.
- Explain, don't prescribe: report what studies found, without doses or advice to start or stop anything; point the user to their doctor for decisions.
