# Clinical trials finder

Needs the ClinicalTrials.gov MCP server (Settings → MCP servers). If it isn't connected, say so and suggest adding it.

## Steps

1. Ask for or confirm the condition and the country or region; don't send personal details beyond what's needed (age range and sex only if the user wants matching).
2. Search for recruiting studies first, then completed ones with posted results if the user wants findings.
3. For each trial: the NCT ID, title, phase, status, what is being tested, the main eligibility points in plain words, and locations near the user if given.
4. Explain phases simply: phase 1 tests safety in a few people, phase 2 looks for effect, phase 3 compares with standard care in many people.

## Rules

- A listed trial isn't a recommendation. Joining one is a decision to make with a doctor.
- Results from a single trial are early evidence; say so.
- Explain, don't prescribe: no treatment advice, no doses.
