# Blacksite 0.1.0

*Draft, 2026-10-26. The first release: paste this into the GitHub release that `desktop.yml` drafts for the `v0.1.0` tag.*

**Run AI agents and teams from one local workspace.** Blacksite is a command center for AI agents that runs on your own computer, with no account and no login. Give each agent a role, a model and the tools it needs, let them work together, and keep their work with the project it belongs to.

This is the first release, and the first one with a desktop app for Windows, macOS and Linux.

## Get it

| System | Download |
|---|---|
| Windows (x64 or Arm) | `Blacksite_0.1.0_x64-setup.exe` or `Blacksite_0.1.0_arm64-setup.exe` (an `.msi` is there for x64 too) |
| macOS (Apple silicon or Intel) | `Blacksite_0.1.0_aarch64.dmg` or `Blacksite_0.1.0_x64.dmg` |
| Linux (x64 or Arm) | `.deb` or `.rpm`, or an `.AppImage` on x64 |

The installers aren't signed yet. On Windows, choose **More info → Run anyway**. On macOS, Control-click the app in Finder and choose **Open**. From this version on, the app checks for updates and asks before installing one.

You can also run it from the source code with [Bun](https://bun.sh): `bun install`, then `bun run start`, and open http://localhost:4800.

## What's in it

### Agents and teams
- **The Station:** a live 3D map of your project, with the Brain in the middle and agents grouped into team pods. Hover a team or agent to light up what it's connected to.
- **The Brain:** a project-wide assistant. Describe what you want and it builds agents and teams, writes the project brief, manages skills, routines and MCP servers, switches models, stops work and hands jobs to the right agent.
- **Team chats:** team members talk in one group chat, each turn streaming in live. The Brain can join in, answer when you write @Brain, and follow up.
- **Mix engines:** Claude Code, OpenAI Codex, Hermes, pi, oh-my-pi, OpenClaw and any OpenAI-compatible API, including local models through LM Studio or Ollama. Team members can use different engines.
- **Library:** ready-made starters and The Agency's 270+ specialists, included with the app.
- **Memory:** every agent and the Brain keep a MEMORY.md file you can read and edit.

### Chats
- Attach files and folders by dropping or pasting them, including images.
- Type **@** to bring in another agent and **/** for commands: `/queue`, `/stop`, `/resume`, `/resend`, `/loop`, `/goal` and `/compact`.
- Long chats are compacted automatically so agents keep the important parts.
- Pick the model and effort level per agent, and star favorite models.
- Rich answers, turned on per agent (off by default).

### Skills and routines
- **Skills:** reusable instructions written in plain words, shared across agents, teams and projects. The Brain can write them, improve them and learn new ones from finished work.
- **Bundled skills:** the storytold Crafting App skills (PhotoCraft, VectorCraft and the rest), OOMOL, Composio and Orca.
- **Routines:** repeatable jobs that mention agents, teams and skills, run by hand or on a schedule.

### Review before anything goes out
- **Needs you:** permission requests wait here. With **The Brain approves** (on by default), the Brain lets routine work through and sends risky or unclear requests to you with a reason.
- **Outbox:** X and Reddit drafts wait for you to approve, edit or reject them.
- **Artifacts:** the results, files and folders agents have saved.

### Your work stays safe
- **Projects:** each has its own agents, teams and chats. Start one in a new folder or an existing one, or clone a GitHub repo.
- **Auto-save:** each project folder keeps a `.dashboard` copy of its agents, teams, routines, chats and skills. Opening the folder again brings it all back.
- **Backups:** **Back up this project** writes one file with every agent, team, skill and preset. Drop it into **New project** to restore it.
- **History:** compare and restore earlier versions of skills, agents, teams and MEMORY.md, and bring back deleted ones.

### Connections
- MCP servers for every engine, with the Brain able to add, change and hand them out when you ask.
- Tools for programs such as Blender, ComfyUI and ffmpeg.
- Accounts for X, Reddit, Telegram and Discord.
- The **Connected to** row shows each connection with its own logo, including the Crafting Apps' own icons.
